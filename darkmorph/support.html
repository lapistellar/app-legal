DarkMorph サポート

使い方（有効化）

  1. 「設定」アプリ →「アプリ」→「Safari」を開く
  2. 「機能拡張」をタップ
  3. 「DarkMorph」をオンにする
  4. 「すべてのWebサイト」を「許可」に設定

サイトが暗くならない / 表示が崩れる場合

アドレスバー左の「あ/A」→ 拡張機能 → DarkMorph、または本体アプリの設定から、そのサイトのモードを「フィルター」や「オフ」に切り替えてお試しください。

DarkMorph Support

Enable via Settings > Apps > Safari > Extensions > DarkMorph, and allow All Websites. If a site looks wrong, switch that site to Filter or Off from the popup or the app. Contact: lapistellar@gmail.com
